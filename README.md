# Turno Nocturno

Survival horror en 2D hecho en Godot. Lalo, un velador nocturno, busca a su compañero Don Chava en un campus universitario vacío durante las vacaciones de diciembre, mientras algo enterrado bajo la universidad empieza a moverse.

## Cómo abrir el proyecto

1. Instala [Godot 4.7](https://godotengine.org/download) o más reciente (versión estándar, no la de .NET).
2. Abre Godot, haz clic en **Importar** y selecciona el archivo `project.godot` de esta carpeta.
3. Presiona **F5** para correrlo.
